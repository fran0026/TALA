# TALA Mother Site (GitHub Pages)

Static mother-site starter for `talaiza.com`.

## Files

- `index.html`
- `styles.css`
- `app.js`

## GitHub Pages (quick)

1. Create a GitHub repository (e.g. `tala-systems-site`).
2. Upload these files to repo root.
3. In GitHub repo settings:
   - **Pages** -> Source: `Deploy from a branch`
   - Branch: `main` / folder: `/ (root)`
4. Add custom domain: `talaiza.com`.
5. Add DNS records (next phase).
