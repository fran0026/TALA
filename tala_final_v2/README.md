# Tala Systems Website

Modern static website for Tala Systems — Lighting the Future of Technology.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## Structure
- `index.html` — primary experience
- `contact.html` — contact page
- `vision.html` — Vision 2035
- `projects/` — project pages
- `pillars/` — existing Faith, Morals, Security and Tech pages can be retained/expanded
- `css/main.css` — new design system and responsive layout
- `js/main.js` — navigation, intro animation and scroll reveals
- `assets/branding/` — primary V2 brand assets
- `assets/leadership/` — leadership imagery

## Local preview
```bash
python3 -m http.server 8080
```
Open `http://localhost:8080`.

## Notes
The existing favicon system is intentionally preserved. The new torch/globe mark is used for the V2 site experience without deleting the previous Tala Systems brand assets.


## V3 Color Direction
- Blue + gold remain the primary Tala signature.
- Green is elevated as a co-dominant brand color.
- White is reserved for text, contrast, and selected content surfaces.
- Light green surfaces provide visual breathing room without breaking the brand.
